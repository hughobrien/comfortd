# Segment 2: change history and live explorer — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every field change seen by the poller is appended to `history.jsonl`, and `https://comfortd.wg/` shows every raw field per unit, live, with recent changes highlighted and a live change feed.

**Architecture:** A store subscriber flattens old/new raw JSON (`internal/jsondiff`) and appends one record per changed path (`internal/history`). The UI follows breezyd: templ components rendered server-side, datastar (vendored JS) connecting to `/ui/sse`, whole-section `outer` patches per unit and `prepend` patches for the feed.

**Tech Stack:** Go, `github.com/a-h/templ`, `github.com/starfederation/datastar-go`, datastar JS bundle (vendored), Nix.

**Spec:** `docs/superpowers/specs/2026-11-07-comfortd-design.md` ("Change history", "Web UI and JSON API"). Builds on segment 1's interfaces (`store.Store`, `store.Update`, `store.Snapshot`, `deps`, `newMux`); read `docs/superpowers/plans/2026-11-07-s1-skeleton-deploy.md` Interfaces blocks.

## Global Constraints

- All segment 1 constraints still hold (no AC writes, no secrets in logs, atomic 0600 state files, SPDX headers).
- `github.com/a-h/templ` version **must equal** `nix eval --raw --inputs-from . nixpkgs#templ.version` (run on bigthink in the repo copy; it was 0.3.1020 on 2026-11-07, the same as breezyd's). Only comfortd's own lock matters here: templ runs only in the gate, not in bigthink's package build. Generate locally with `go run github.com/a-h/templ/cmd/templ@v<that version> generate`. Commit the generated `*_templ.go` files.
- `datastar-go`: newest release. The vendored JS bundle is the matching datastar release's `bundles/datastar.js`, saved as `cmd/comfortd/ui/vendor/datastar-<version>.min.js`, sha256 recorded in `cmd/comfortd/ui/vendor/README.md` (same table as `../breezyd/cmd/breezyd/ui/vendor/README.md`).
- `history.jsonl` record shape, exactly: `{"t":RFC3339 UTC,"unit":slug,"endpoint":…,"path":…,"old":…,"new":…}` plus optional `"source"`; `old`/`new` are strings holding the JSON encoding of the value, `"null"` when absent.
- Rotation at 50 MB to `history.jsonl.1` (one generation).
- Noisy paths, dimmed in the UI: `updatedAt`, `lastStatusChangeAt`, `rssi`, `routerRssi`, `lastUpdated` (match on the last path segment).
- "Recently changed" = a history record for that unit/endpoint/path within the last 10 minutes.
- SSE responses set `X-Accel-Buffering: no` and clear the write deadline (see `../breezyd/cmd/breezyd/handlers_ui_sse.go`).

## Review Focus

1. **Arrays and nested objects in diffs:** `holdMode` (object) and the profile (array) must diff per leaf, not as one blob. Pinned in Task 1 (`TestFlattenNested`).
2. **A key disappearing** (`realValues.spHeat` present, then `realValues` is `{}`): it must produce a record with `new:"null"`, and `{}` itself must show as a leaf. Pinned in Task 1 (`TestDiffKeyRemoved`).
3. **Daemon restart:** no burst of fake "changes" (first sight records nothing), and the feed shows history from before the restart. Pinned in Task 2 (`TestRecentSurvivesReopen`) and Task 3 (`TestNoRecordsOnFirstSight`).
4. **Slow or stuck browser tab:** one stuck SSE subscriber must not block the poller. Pinned in Task 5 (`TestHubDropsWhenFull`).
5. **Browser reconnect:** a reconnecting EventSource must not duplicate unit sections. Pinned in Task 5 (`TestSSEReconnectUsesOuter`).

### Task 1: JSON flatten and diff

**Files:** Create `internal/jsondiff/jsondiff.go`, `internal/jsondiff/jsondiff_test.go`

**Interfaces:**
- Produces:
  ```go
  func Flatten(raw json.RawMessage) (map[string]string, error) // path → compact JSON of the leaf
  type Change struct{ Path, Old, New string }                  // Old/New "null" when absent
  func Diff(old, new map[string]string) []Change               // sorted by Path
  ```
  Path rules: object keys joined with `.`, array indices as `[i]` (`[0].maximumSetPoints.heat`, `holdMode.enabled`); empty object leaf `{}`, empty array leaf `[]`; scalars as compact JSON (`19`, `20.5`, `"heat"`, `true`, `null`).

### Task 2: History log

**Files:** Create `internal/history/history.go`, `internal/history/history_test.go`

**Interfaces:**
- Produces:
  ```go
  type Record struct {
      T        time.Time `json:"t"`
      Unit     string    `json:"unit"`
      Endpoint string    `json:"endpoint"`
      Path     string    `json:"path"`
      Old      string    `json:"old"`
      New      string    `json:"new"`
      Source   string    `json:"source,omitempty"`
  }
  func Open(path string, maxBytes int64) (*Log, error)   // loads the last 1000 records from path (and .1 if needed) into memory
  func (l *Log) Append(recs ...Record) error              // one JSON line each, fsync not required
  func (l *Log) Recent(unit string, limit int) []Record   // newest first; unit "" = all; from memory
  func (l *Log) ChangedSince(unit, endpoint string, since time.Time) map[string]bool // paths with a record after since
  func (l *Log) Subscribe(fn func(Record))                // called after each appended record
  func (l *Log) Close() error
  const DefaultMaxBytes = 50 << 20
  ```

**Interfaces:**
- Produces:
  ```go
  package ui
  type Row struct{ Path, Value string; Changed, Noisy bool }
  type EndpointView struct{ Name, At, Error string; Rows []Row } // At formatted "15:04:05"
  type UnitView struct{ Slug, Name, Serial string; Stale bool; LastOK string; Endpoints []EndpointView }
  ```

  ```go
  package main
  type pushEvent struct{ Slug string; Record *history.Record } // Slug set: re-render unit; Record set: prepend feed row
  type pushHub struct{ … }

  func (h *pushHub) Subscribe() (<-chan pushEvent, func()) // buffered 32; second return unsubscribes
  ```

    - Sends a keepalive comment every 30 s.
  - Wiring in `main.go`: `store.Subscribe` → `hub.Publish(pushEvent{Slug})`; `history.Subscribe` → `hub.Publish(pushEvent{Record: &r})`.
